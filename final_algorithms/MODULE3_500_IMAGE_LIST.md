# Module 3 pilot — the 500-image list

The image worklist that Stage 1 (Module 1) and Stage 2 (Module 2) feature
extraction runs over, to populate `data/module3_stage1_features.csv` and
`data/module3_stage2_features.csv`.

Generated by [`python/select_module3_ids.py`](python/select_module3_ids.py)
with `--seed 0`. Source of truth for the ids is `data/module3_ids.txt`;
this document is the human-readable view of the same selection.

Run the extraction with:

```matlab
extractModule3Features(IdsFile="data/module3_ids.txt", SplitsFile="data/module3_splits.csv")
```

## Severity spread

Deliberately **grade-balanced at 100 per grade**, not at APTOS's true
prevalence — so the model sees enough severe and proliferative cases to
learn from (Module3_Plan.md §5.1, decision D2).

| | **total** | **500** | 100% | | 3662 |

> Because sampling is balanced, positive predictive value and any operating
> threshold chosen on this set are **not** what screening would see.
> Reweight to the true mix before quoting predictive values (§5.1).
